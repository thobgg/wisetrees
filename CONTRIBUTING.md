# Mitmachen · Contributing

**Deutsch**

Ideen und Fehlerberichte sind willkommen – bitte als Issue. Hilfreich bei Fehlern: was erwartet war, was passiert
ist, die Fassung von wisetrees und, wenn es um Daten geht, ein kleiner GEDCOM-Ausschnitt mit erfundenen Namen.

Fremden Code (Pull Requests) nimmt das Projekt vorerst nicht an. Solange es keine Beitragsvereinbarung gibt, bleibt
die Urheberschaft an einer Stelle; das hält die Lizenzfrage einfach. Vorschläge für Änderungen am Code gern als
Issue mit Beschreibung.

**English**

Ideas and bug reports are welcome – please open an issue. Helpful for bugs: what you expected, what happened, the
wisetrees version and, if data is involved, a small GEDCOM excerpt with made-up names.

The project does not accept code from others (pull requests) for now. As long as there is no contributor agreement,
copyright stays in one place, which keeps licensing simple. Proposals for code changes are welcome as an issue with
a description.
